# Версия сайта на хинди: завершение текстового перевода

Основа: русский репозиторий `AleksandrSpiridonov/catoblepaspress`, ветка `v5`, коммит `5ba10ed2470f02dfe63855665db6ae8998f51408`. История сохранена; русский сайт не изменён.

## Результат

Перевод текстовой части сайта завершён в согласованном объёме: 58 публикуемых страниц на хинди. Включены главная и разделы, 17 авторских страниц, 5 книжных карточек, 3 интервью, документы, проекты, описания и управление просмотром 9 выпусков журнала, оригинальные публикации. «Всемогущий» представлен только ознакомительным фрагментом. Статья о «Мосте на Дрине» содержит переведённый авторский текст и сохранённые русские цитаты из перевода романа.

Итальянское стихотворение Елизаветы Калужской переведено непосредственно с итальянского оригинала. В интервью сохранены все реплики (Лебедев — 34, Медведев — 29, Навка — 43), даты, ссылки и видео. В карточке выпуска № 34 исправлено исходное описание, ошибочно называвшее его двадцать первым выпуском.

Сайт: https://hi.catoblepaspress.ru/. GitHub Pages работает через вручную запускаемый workflow `deploy.yml`, HTTPS включён. Аналитика русской версии отключена; подтверждение возраста независимо сохраняется в локальном хранилище браузера. Документы о данных и cookie поясняют отличие от основного русского сайта.

## Границы результата

- Не переводились повторно 12 страниц, перечисленных в `tools/untranslated-sources.json`: раздел `publications/translations/` и `publications/fies.md`. Их исходные тексты защищены контрольными суммами; посетителю показано пояснение на хинди.
- Сохранены русские цитаты перевода романа в `thebridgeonthedrina.md`, а также цитированные строки на исходных языках в подборке анимации. Авторский текст страниц переведён. Язык цитат указан отдельно.
- «Всемогущий»: только первые 12 абзацев главы 1, до «Несколько недель назад Всемогущий исчез». В конце — `ungh@catoblepaspress.ru` для всех вопросов и ссылка https://catoblepaspress.ru/publications/almighty на полный русский текст.
- Встроенные PDF, EPUB, формы, аудио, видео и текст внутри изображений выпусков не переводились и не перевёрстывались. На страницах указаны исходные языки. Перевод страницы книги или выпуска не означает перевод самого издания.
- Два черновика и шаблоны не публикуются.
- Перевод пока не проходил редакторскую проверку носителем хинди.

## Проверки

```sh
npm ci
npm run install-plugins
npx tsc --noEmit
npm test
node quartz/bootstrap-cli.mjs build --concurrency=1
node tools/verify-hi.mjs
```

Все 168 тестов и TypeScript прошли. Проверяются canonical URL, ссылки и якоря всех 58 страниц, CNAME, изоляция аналитики, все исключения и объём фрагмента. Проверка полноты запрещает появление непереведённой публикуемой страницы вне явного списка исключений.

`tools/final-source-manifest.json` фиксирует URL, цели wikilinks, количество реплик и медиастраниц последнего этапа относительно коммита `06569dceb643316ccec149157b4e90b095632547`, а также контрольные суммы цитат романа. Сохранены 27 записей книжного клуба, 43 записи киноклуба и 16 медиастраниц антологии. Старые русские aliases и используемые якоря сохранены.

`tools/prepare-hi.ts` воспроизводимо добавляет словарь хинди в пакеты Quartz и собирает переключатель языков после установки зависимостей. Шрифт — Noto Sans Devanagari.
